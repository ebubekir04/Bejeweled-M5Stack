# Bejeweled for M5StickC Plus2

This is a C implementation of the classic game Bejeweled, developed for the M5StickC Plus2 (ESP32).

## Features
- **Accelerometer Controls:** Move the cursor by tilting the device.
- **Save/Load System:** Game state is persistently stored using EEPROM.
- **Game Logic:** Handles matching sequences of 3 or more gems and gravity for falling gems.

## Technical Details
- Language: C++ (Arduino/M5Unified framework)
- Hardware: M5StickC Plus2
- Memory management: Optimized for embedded flash storage.
